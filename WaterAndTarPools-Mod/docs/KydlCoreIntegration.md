# KydlCore integration

Uses `KydlCore.Core` (`IFeature`, `FeatureRegistry`, registered in `ModInstaller`), the shared log and input lock from `KydlCore.Common`, and the hub through `KydlCore.Features.Hub.Contracts.KyHub` (title "Water And Tar Pools", the described page `pools` and the `settings` tab with every config entry, F6). The sign editor is a KydlCore window. KydlCore is a hard dependency.
